# ⚛️ Newton's Cradle Simulation

A physics simulation built with JavaScript, **p5.js**, and the **Matter.js** physics engine modeling a classic Newton’s Cradle with interconnected ropes and bob constraints.

🔗 **[Play the Live Demo](https://anushreya-satish.github.io/Newton-Cradle/)**

## 🎮 Controls
* **Up Arrow Key:** Apply a force to pull back the first bob and release it into the cradle.

## 💡 What I Practiced
* Using Matter.js `Constraint` to attach multiple physics bodies to a static roof object like ropes.
* Managing multi-body collision physics and momentum transfer.
* Structuring code with custom classes (`roof`, `bob`, `rope`) for clean object-oriented physics design.
